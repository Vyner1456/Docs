## Key Topics:

**About GitHub Apps**
- GitHub Apps are integrations that automate processes and extend GitHub's functionality
- They can act on behalf of a user OR independently
- Common use cases: automating tasks, "Sign in with GitHub," developer tools, and service integrations

**Building a GitHub App involves:**
1. Registering a GitHub App
2. Writing code to add functionality
3. Making authenticated requests to GitHub's APIs
4. Hosting your app (on a server or user's device)
5. Installing it on your account

**Types of GitHub Apps:**
- **User-acting apps**: Use user access tokens; limited by app permissions and user's permissions
- **Self-acting apps**: Use installation access tokens; limited by app permissions only
- **Webhook-responding apps**: Subscribe to GitHub events and react to them
- **Permission-controlled apps**: Select specific permissions that determine what the app can do

**What happens next:**
- Private apps can only be installed by the owning account
- Public apps can be installed by other accounts and shared via GitHub Marketplace
